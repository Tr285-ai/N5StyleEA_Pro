# N5StyleEA v15.3

Advanced AI-powered trading system with support for multiple strategies and brokers.

## Features

- Multiple trading strategies (mean reversion, momentum, pairs trading, etc.)
- Advanced risk management
- Backtesting framework
- Real-time trading
- Web interface
- Docker support

## Quick Start

```bash
# Clone the repository
git clone [https://github.com/yourusername/N5StyleEA.git](https://github.com/yourusername/N5StyleEA.git)
cd N5StyleEA

# Install dependencies
pip install -r requirements.txt

# Copy and configure environment
cp .env.example .env
# Edit .env with your configuration

# Run the bot
python main_v15_2.py
