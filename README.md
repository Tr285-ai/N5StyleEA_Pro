# N5StyleEA Pro v15.3 - AI-Powered Trading Platform

N5StyleEA_Pro v15_3 – AI-powered trading Expert Advisor with FastAPI backend, TensorFlow models, and risk management.

A sophisticated algorithmic trading system with AI assistance, real-time data, and secure authentication.

## Features

- AI-Powered Trading: Get AI-based trade suggestions and analysis
- Multiple trading strategies (mean reversion, momentum, pairs trading, etc.)
- Real-time data (WebSocket-based)
- Backtesting framework with performance metrics
- Advanced risk management
- Extensible design to add new strategies and indicators
- Performance analytics and TCA reporting
- Web interface
- Docker support

## Prerequisites

- Python 3.8+
- pip (Python package manager)
- Git (optional)

## Quick Start

```bash
# Clone the repository
git clone https://github.com/Tr285-ai/N5StyleEA_Pro
cd N5StyleEA_Pro

# Install dependencies
pip install -r requirements.txt

# Copy and configure environment
cp .env.example .env
# Edit .env with your configuration

# Run the bot
python main_v15_2.py
```
