==========

1. Configure your API keys in [.env](cci:7://file:///c:/N5StyleEA_Pro%20v15_3/.env:0:0-0:0):

      cp .env.example .env

      # Local run
      python main_v15_2.py

      # Or with Docker
      docker-compose up
