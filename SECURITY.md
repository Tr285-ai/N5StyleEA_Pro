# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 15.x    | :white_check_mark: |
| < 15.0  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in N5StyleEA, please follow these steps:

1. **Do not** create a public GitHub issue for security vulnerabilities
2. Email the security team directly at [your-email@example.com](mailto:your-email@example.com)
3. Include a detailed description of the vulnerability
4. Include steps to reproduce the vulnerability
5. We will acknowledge your email within 48 hours
6. We will keep you informed of the progress towards fixing the vulnerability

## Security Updates

Security updates will be released as patch versions (e.g., 15.3.1, 15.3.2) for the latest minor version.

## Security Best Practices

- Always keep your API keys secure
- Use environment variables for sensitive information
- Regularly update to the latest version
- Use strong, unique passwords
- Enable two-factor authentication where possible
- Regularly review access logs and permissions
