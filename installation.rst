Installation
============

Prerequisites
-------------
- Python 3.9+
- Docker (optional)
- Git

Using pip
---------
.. code-block:: bash

   git clone https://github.com/yourusername/N5StyleEA.git
   cd N5StyleEA
   pip install -r requirements.txt

Using Docker
------------
.. code-block:: bash

   git clone https://github.com/yourusername/N5StyleEA.git
   cd N5StyleEA
   docker-compose up -d
